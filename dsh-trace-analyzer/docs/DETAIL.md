# Trace Lab

把当前会话的 trace 事件日志变成产品级可视化视图，挂在主对话区视图环（紧邻内置「轨迹」）。

## 用法

1. 打开任意会话，在主对话区视图环（与「对话 / 轨迹」同排）点击「Trace Lab」Tab。
2. 视图内展示「运行总览」：KPI 大卡片 + 可展开的 run 表（点行就地展开 step → 操作）。

## 能力（分阶段交付）

- 运行总览（单视图）：KPI 大卡片（run/step/事件/Token/错误/慢/异常/最慢）+ 可展开 run 表（run 文字定宽 + 时间/Token 条 + 按时间/按 Token 排序）；点行就地展开 step → 操作，操作日志 JSON
- Step 行：序号与 run 对齐，条内数值的排布与 run 条一致，另一维度在条后常驻，并有一行文字摘要；同一时刻只选中一个 step，选中态与其 run 分组连成一条强调轨
- 展开的 run 与其全部 step 是一个着色分组（淡蓝底 + 连续左轨），整体性不依赖选中
- Step 内容直出：点开 step 出现卡片容器，顶部一行构成概览（模型 / 模型调用 N / 工具调用 N / 上下文 N / 计时 / Token），下面**按事件顺序**列出该步的痕迹：用户指令 → 模型调用（文本 + token）→ 每个工具调用（参数 / 结果 / 耗时 / 错误）→ 上下文注入 → 系统提示词；原始 JSON 作为每行的「原文」可选展开
- 角色标签与内置「轨迹」对齐（用户 / 助手 / 上下文 / 系统 / 工具，同款配色与标签样式）：Run 行标触发者，Step 明细行标每一段的来源角色
- 打开即 KB 级加载（约 27 KB 首屏，服务端 ~20 ms），展开 run 才拉步索引（≤40 KB）、点 step 才拉该步内容（p95 2 KB）
- 会话执行树（以 run 为统计单位，run0 = 系统提示词）
- 事件详情查看器（完整 JSON + surface + 来源/替换链）
- 搜索与过滤、导出（JSON / JSONL / 复制）
- 深浅色主题适配

## 数据来源

只读使用 DSH 的 `sessionQuery` 服务（`listEvents` / `readEvent` / `readSession` / `traceSession` / `traceEvent` / `filterEvents`），不修改任何会话事件。

## 局限

- v1 仅分析当前会话，不做跨会话对比。
- 已移除「血缘」视图（官方轨迹亦无此数据类目）。

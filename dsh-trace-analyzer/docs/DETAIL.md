# Trace Lab

把当前会话的 trace 事件日志变成可读的视图，挂在主对话区视图环（紧邻内置「轨迹」）。

## 用法

1. 打开任意会话，在视图环点击「Trace Lab」。
2. 顶部是热力矩阵：三行指标（Time / Token / Steps）+ 一行错误/慢标记，每个 run 一列。
   指针扫过一列 → 列表聚焦该 run（其余压暗）；点击 → 该 run 停在列表顶部并展开。
3. 点 Step 行展开该步内容：`REPLY`（模型回复与 in/out token）/ 工具卡（名字 + 耗时 + args + result）/
   `CTX`（运行时注入，合并计数）/ 说明行（压缩、重试、失败、文件变更…）。每张卡片底部都有 `RAW` 下拉，
   展开即该事件的原始 JSON（首屏最多 2 万字符，超出可「show all」）。

## 口径

- 统计单位是 **run**（一次真实用户指令），`run 0` 是系统提示词。
- Step 耗时 = 模型 + 工具，**人机等待单列**（`⏸`）不计入。
- 打开即落在最新 run，并随对话实时跟随；上滚查看历史后，右下角「↓ Latest」可回到实时位置。

## 数据来源

只读使用 DSH 的 `sessionQuery`（`inspectSession` / `readSession` / `readEvent`），不修改任何会话事件。

## 局限

- 仅分析当前会话，不做跨会话对比。
- 无血缘树、搜索过滤、导出（官方轨迹亦无血缘类目）。
